# inbox 使用说明

这是**单层平盆收件箱**,故意不分子目录。

唯一规则:**分不清/懒得分类的混杂资料,无脑丢进 inbox 根目录即可,不要在录入时纠结类别。**

分类是 LLM 的工作,不是录入者的工作。LLM 定期读取 inbox,判断类型、去重、拆分,然后分发到最终工作区:

- 可复用知识 → `知识管理/`
- 临散杂卡、快查备忘 → `备忘录/`
- 灵感、选题 → `灵感库/`
- 稿件、脚本 → `光的房间稿件/`
- 需保原貌的原始资料 → `LLM知识库系统/raw/`
- 跨文档结论 → `LLM知识库系统/wiki/`
- 一次性但有长期价值的分析 → `LLM知识库系统/queries/`

> 注意:如果你录入时**已经明确知道**某条属于稿件/说明书/灵感等,直接放对应最终工作区,不必经过 inbox。inbox 只服务于"暂时分不清"的那部分。

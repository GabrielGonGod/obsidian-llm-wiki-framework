## 处理方法（务必照此，已实测）
1. 路径：左侧「我的」→收藏→视频。**不要用 `video/{id}` 网址**（会重定向到推荐流）。
2. 在网格里**点击卡片**打开 → 右侧「问AI」→ 点「视频总结」生成结构化总结。
3. 作者看视频左下 `@用户名`；五角星点亮(黄)=已收藏。
4. **排除作者**：`光的房间`(本人)、`做家具的兵哥哥` → 跳过不建卡。
5. 卡片写入 `LLM知识库系统/inbox/`，frontmatter 含平台/链接/作者/收藏日期/已转写。
